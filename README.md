# Coffee Shop Sales Analytics
**A multi-page Power BI report for monitoring sales, budget performance, products and customer segments.**

</div>

## Project overview
This Power BI project contains four report pages designed to explore coffee shop performance from different business perspectives.

## Report pages
| Page | Focus |
|---|---|
| Sales Overview | High-level sales performance |
| Budget and Performance | Actual performance compared with budget |
| Product Performance | Product-level performance |
| Customer & Segment Analysis | Customer and segment analysis |

## Tools
- Microsoft Power BI
- Power Query
- DAX

3. Navigate through the four report pages and use the available filters/interactions.
